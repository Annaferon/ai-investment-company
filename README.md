# AI Investment Company

Сеть ИИ-агентов для торговли на российском рынке и глобальных рынках.

## 🎯 Что это

Самоанализируемая AI-компания, которая:
- торгует виртуальным капиталом (10 000 ₽) на реальных данных
- анализирует акции РФ, криптовалюты и драгметаллы
- развивается: нанимает новых агентов, увольняет неэффективных
- проходит полный цикл аудита каждого решения

## 🏗 Архитектура

- **Orchestrator**: координация агентов
- **Oracle**: сбор данных (MOEX, Binance, ЦБ РФ)
- **Agents**: Trader, Analyst, Auditor, CEO и др.
- **Broker**: виртуальный торговый движок
- **Portfolio**: учёт позиций и P/L

## 📦 Стек

- Python 3.10+
- PostgreSQL (Supabase)
- OpenRouter (LLM)
- Render (хостинг)
- Telegram (интерфейс)
